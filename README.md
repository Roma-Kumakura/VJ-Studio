# VJ STUDIO

自作曲（Sunoで作った曲もOK）に合わせて自動で動くVJ映像を、ブラウザだけで作ってMP4で書き出すWebアプリ。AIは使わず、信号処理と手続き生成だけで動きます。曲・画像・動画は外部に送信されません。

## 使い方
1. 曲をドロップ（wav / mp3 / m4a / flac）。Sunoのmp3なら曲名・ジャケット・歌詞も自動で読み取ります
2. 「テーマ」で映像を選び、🎲でランダムに生成し直す
3. プロフ（アイコン・@ID）、メーター（スペアナ5種・波形・位相）、写真動画、歌詞、テロップ、エフェクトで仕上げる
   - プレビュー上の要素はクリック → ドラッグで移動、ホイール / ピンチでサイズ変更
4. 「書き出し」で比率（16:9 / 1:1 / 9:16）・画質・区間を選んでMP4を保存
5. 「おまかせ」タブのスロットで丸ごと自動生成。スーパースロットでは、テーマと写真が人工生命として曲の中で進化します

しくみの解説は `about.html`（アプリ右上の「?」）にあります。

## 開発
```bash
npm install
npm run dev     # http://localhost:5173
npm test        # 解析・歌詞タイミング・シーン構成・人工生命のテスト
npm run build   # dist/ に静的サイトを出力（どの静的ホスティングでも動きます）
```

## 構成
- `src/analysis/` 音声解析（FFT・帯域・オンセット・BPM・展開判定）。Web Workerで実行
- `src/templates/` 映像テーマ68種（GLSL / Canvas2D）。すべて時刻 t の関数なのでプレビューと書き出しが一致
- `src/app/` おまかせ（ディレクター）、曲の展開に沿ったシーン構成、スーパースロット（人工生命＋キュレーター）
- `src/core/` 共通の合成処理（ブルーム・キラキラ・写真/動画レイヤー）、HUD（アイコン・メーター・歌詞・テロップ）、フォント
- `src/export/` WebCodecs + mp4-muxer によるコマ落ちなしMP4書き出し（非対応ブラウザはリアルタイム録画で書き出し）
- `src/ui/` エディタUI（タイムライン・各種コントロール・生態系グラフ）
- `src/about/`, `about.html` しくみの解説ページ（グラフはページ内で実際に計算）
